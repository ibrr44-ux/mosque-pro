### الخطوة 1: فتح التطبيق
```

```
1. الإعدادات → إدارة المجلد الآمن

```

2. نافذة إدارة تفتح
3. ادخل اسم مسجدك
4. اضغط: "إضافة"
```

```
أضف المعدات والمهام والأعطال والبيانات المالية
```

## 💾 نموذج البيانات

### هيكل المجلد
```
مجلدك/
├── config.json                    # قائمة المساجد
├── mosque_M1234567890.json        # مسجد 1
├── mosque_M1234567891.json        # مسجد 2
└── mosque_M1234567892.json        # مسجد 3
```

### config.json (مثال)
```json
{
  "mosques": [
    {
      "id": "M1234567890",
      "name": "جامع الكبير",
      "createdAt": "2026-05-08T10:30:00.000Z",
      "dataFile": "mosque_M1234567890.json"
    }
  ]
}
```

### mosque_*.json (مثال)
```json
{
  "tasks": [...],
  "issues": [...],
  "finances": [...],
  "equipment": [...],
  "_meta": {...}
}
```

## 🎓 النصائح والحيل

### ✅ أفضل الممارسات
```
1. سمّ المساجد بأسماء واضحة
2. احفظ النسخ الاحتياطية أسبوعياً
3. استخدم الباركود للتميز
4. تحقق من المسجد الصحيح
5. شارك الملفات بحذر
```

### ⚠️ تجنب الأخطاء
```
1. لا تمسح المسجد عن طريق الخطأ
2. لا تشارك كل الملفات
3. لا تتجاهل التحذيرات
4. لا تعمل دون اختيار مسجد
```

## 🆘 استكشاف الأخطاء

### المشكلة: لا يظهر أي مسجد
**الحل:** أضف مسجد جديد من خلال نافذة الإدارة

### المشكلة: البيانات لم تُحفظ
**الحل:** 
- تحقق من اتصال File System
- جرّب إعادة الربط
- استخدم "تصدير" للنسخ الاحتياطية

### المشكلة: تسرب بيانات بين المساجد
**الحل:** تأكد من اختيار المسجد الصحيح قبل الإضافة
